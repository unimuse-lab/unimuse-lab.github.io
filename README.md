# unimuseLab（um.Lab）

VRChat向けのツールとサービスを作っている個人開発ラボ「um.Lab」の公式サイトです。

**公開サイト:** https://unimuse-lab.github.io/

## コンテンツ

### プロフィール（トップページ）

- um.Lab の紹介
- BOOTHで販売中のツール（マテリアル一括置換ツール／Universal Toggle）
- BOOTHアイテム検索プラットフォーム「Kaidoki」の紹介
- 各種リンク（GitHub／BOOTH／X）

### 改変ガイド・手順書（guide/）

VRChatアバター改変の初心者向け手順書です。

1. [環境構築：UnityとVRChat SDKの準備](guide/setup.html) — Unity Hub、VCC（VRChat Creator Companion）、指定バージョンのUnityを入れてプロジェクトを作るまで
2. [バージョンが違う・エラーが出たときの切り分け](guide/version-trouble.html) — バージョン不一致や赤いエラーの確認ポイントと対処の早見表

目次は [改変ガイド・手順書トップ](guide/index.html) からたどれます。
